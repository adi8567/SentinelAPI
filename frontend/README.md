# SentinelAPI Frontend

This directory houses the Next.js 15 (App Router) + TypeScript frontend application scheduled for Phase 6.

## Planned Architecture
- Next.js 15 (App Router) + React Server Components
- Tailwind CSS + shadcn/ui components
- High-Performance Visualizations: Recharts, Apache ECharts, Nivo
- React Query (TanStack Query) for real-time WebSocket and polling synchronization
- Responsive Dark/Light mode theme engine
